# Authentication Test Plan

## Scope
Login, logout, password reset, session management, lockout, remember-me and protected-resource access.

## Approach
Functional, negative, boundary, usability and regression testing with browser DevTools for basic client-side validation checks.

## Entry Criteria
Test build available and test accounts created with non-production data.

## Exit Criteria
Critical authentication scenarios pass and no unresolved blocker/critical defects remain.
